# Entrega del Mapa Conceptual Digital

En esta carpeta se deben alojar los archivos finales correspondientes al mapa conceptual colaborativo desarrollado por el equipo de trabajo.

---

## 📁 Archivos requeridos en este directorio

1. **Documento en formato PDF:**
   - Nombre sugerido: `Mapa_Conceptual_Sistemas_Distribuidos.pdf`
   - Debe ser exportado directamente desde la herramienta utilizada (**Miro** o **draw.io**) en alta resolución para permitir la lectura clara de cada nodo, definición y referencia.

2. **Archivo Fuente:**
   - Si se utilizó **draw.io**: Adjuntar el archivo con extensión `.drawio` o `.xml`.
   - Si se utilizó **Miro**: Adjuntar la exportación vectorial (`.svg` / `.pdf` vectorial) o copia de respaldo según la disponibilidad de la plataforma.

## ✅ Lista de Verificación (Checklist de Cumplimiento)

Antes de realizar la entrega final y el commit definitivo, verifiquen el cumplimiento de los siguientes puntos exigidos en la rúbrica:

- [ ] **Ecosistema Temático Completo:**
  - [ ] Tipos de sistemas distribuidos.
  - [ ] Modelos de comunicación.
  - [ ] Middleware.
  - [ ] Conceptos de transparencia.
  - [ ] Tolerancia a fallos.
  - [ ] Teorema CAP (Consistencia, Disponibilidad, Tolerancia a Particiones).
- [ ] **Relaciones Explícitas:** Existen conectores semánticos y líneas de relación entre los diferentes componentes del ecosistema.
- [ ] **Extensión de Definiciones:** Cada concepto contiene una breve definición con un **máximo estricto de 20 palabras**.
- [ ] **Referencias Verificadas:** Cada concepto cuenta con **al menos dos (2) referencias bibliográficas verificadas**, publicadas en los **últimos 5 años**.
- [ ] **Archivos Adjuntos:** El PDF final y el archivo fuente se encuentran subidos a esta carpeta.
